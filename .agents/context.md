### 📝 Контекст Проекта (PRD): Сказки: Перекрестки Судеб (Fairy Tale Crossroads)

#### 1. Обзор продукта и бизнес-контекст
Мы разрабатываем игру в жанре интерактивной визуальной новеллы по мотивам сказок в экосистеме **Telegram Bot + Telegram Mini App (TMA)**. Главное УТП: игроки погружаются в знакомые сказки, но сами принимают решения, меняющие сюжет (романтика, драма, злодейский путь). Детали сюжета и концепции описаны в файле "Игра".
**Монетизация:** Просмотр рекламы (Rewarded Ads) для получения премиум-валюты (Кристаллы) и восстановления энергии (Ключи), а также покупка премиум-выборов.

#### 2. Технический стек и Инфраструктура
Проект строится на современной Serverless-архитектуре, чтобы легко масштабироваться и работать в Telegram.
*   **Frontend (TMA):** React.js (Vite / Next.js), Telegram Web App SDK, TailwindCSS[cite: 2, 6].
*   **Backend / API:** Serverless Edge Functions (Node.js/TypeScript)[cite: 6].
*   **База данных (База знаний):** Supabase (PostgreSQL)[cite: 2, 6].
*   **Хостинг / Деплой:** Vercel[cite: 2, 6].
*   **Telegram Bot:** Интеграция через Webhooks (из-за ограничений Vercel Serverless)[cite: 2, 6].

#### 3. Архитектура и Модели Данных (Supabase PostgreSQL)
*   **Пользователи (`users`):** `id`, `telegram_id`, `username`, `crystals` (премиум-валюта), `keys` (энергия), `created_at`[cite: 4].
*   **Сюжет и Контент:** Таблицы `stories` (Сказки) и `episodes` (Главы)[cite: 4].
*   **Прогресс (`user_progress`):** Текущая история, пройденные узлы сюжета, накопленные статы (Свет/Тьма) и купленные премиум-выборы[cite: 4].

#### 4. Требования к Безопасности (Security Guidelines)
*   **Аутентификация:** Обязательная валидация `initData` через HMAC-SHA256 подпись Telegram Bot Token для всех запросов с фронтенда[cite: 2, 6]. Все решения об идентичности пользователя принимаются только на сервере[cite: 3].
*   **Защита от IDOR/BOLA:** Серверная проверка прав (deny-by-default) на каждом эндпоинте. Проверка принадлежности объекта прогресса текущему авторизованному `telegram_id`[cite: 3].
*   **Исключение Mass Assignment:** Игнорирование клиентских полей (нельзя передать скрытые поля вроде баланса кристаллов или ключей при обновлении прогресса)[cite: 3]. Начисление валюты происходит строго через защищенные серверные транзакции.
*   **Защита от утечек:** Ошибки для клиента должны быть минимальными. Запрещено возвращать stack trace или переменные окружения в ответах API[cite: 3].

#### 5. UX/UI и Производительность
*   **Скорость:** Время первичной загрузки TMA должно составлять < 1.5 секунды[cite: 2, 6].
*   **Дизайн:** Строго следуй принципам Apple HIG и Telegram Design System, поддерживай мобильную адаптивность[cite: 2, 6]. Блокировка системных свайпов вниз, чтобы игра не закрывалась случайно во время чтения диалогов.

#### 6. Руководство по локальному запуску (Dev Environment)
*   **Frontend + API (Vite):** Запуск через команду `npm run dev` (доступно на localhost:3000, включает встроенный роутинг эндпоинтов /api/)[cite: 7].
*   **Telegram Bot:** Запуск через команду `npm run bot` (режим Long Polling для локальной разработки)[cite: 7].

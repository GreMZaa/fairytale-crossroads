# 🔍 Claude SEO & Telegram Previews

SEO-аудит и оптимизация мета-данных для Telegram Mini App и веб-лендингов визуальной новеллы.

## 📱 Ключевые фокусы для Telegram:
1. **Telegram WebApp Rich Previews:**
   - Оптимизация тегов `<meta property="og:image">`, `og:title`, `og:description` для идеального отображения сниппета игры при отправке ссылки в Telegram-чатах и каналах.
   - Размер превью: 1200x630px без обрезок по краям.
2. **Schema.org Structured Data:**
   - Разметка `VideoGame` и `SoftwareApplication` для поисковиков (Яндекс, Google).
3. **Canonical & Viewport:**
   - Корректная настройка viewport для исключения масштабирования в мобильных браузерах.

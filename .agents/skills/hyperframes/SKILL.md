# 🎬 Hyperframes (Code-to-Video & Canvas Animations)

Генерация интерактивных и рендеримых в видео анимаций на базе HTML5 Canvas, CSS keyframes и Three.js/WebGL для промо-материалов, тизеров новых глав и катсцен визуальной новеллы.

## 🌟 Возможности:
1. **Тизеры глав для Telegram:** Генерация послойных анимированных кадров (фон с эффектом параллакса, мерцание магии, появление диалоговых реплик).
2. **Интерактивные катсцены в новелле:** Отрисовка спецэффектов (снежная буря в «Ледяной башне», вспышки заклинаний, анимация открытия сундуков с кристаллами).
